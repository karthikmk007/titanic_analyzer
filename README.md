# Titanic Survival Analysis

A repository reserved for a beginner-friendly data-analysis and machine-learning study using the Titanic dataset.

## Status

The repository currently contains documentation only. There is no notebook, dataset pipeline, trained model, or verified result yet.

## Intended learning outcomes

- inspect schema and missing values;
- distinguish categorical and numerical features;
- prevent train/test leakage;
- create reproducible preprocessing;
- build a simple baseline before complex models;
- evaluate classification performance beyond accuracy;
- explain which conclusions are supported by the data.

## Minimum professional deliverable

```text
.
├── notebooks/01_exploration.ipynb
```
